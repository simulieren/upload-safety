An upload passes only when its extension, its declared MIME type and its bytes agree, and when it carries nothing that runs on its own. Built for apps that take CVs, invoices, contracts and photos from strangers and hand them to colleagues who open them in Office or Acrobat.

```sh
npm install upload-safety
```

```ts
import { checkUpload } from 'upload-safety';

const result = checkUpload( { filename, mimeType, bytes }, { maxBytes: 10 * 1024 * 1024 } );
if ( ! result.ok ) {
	// result.reason: 'macros', 'encrypted', 'content-mismatch', ...
}
// Store result.bytes under result.filename with result.mimeType.
```
